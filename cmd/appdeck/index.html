Ceilings

Every import must fit these. Downloads and uploads are held in memory whole, so the body cap also bounds RAM use; the expanded cap bounds what an archive may unpack to on disk (zip bombs included). 0 = no limit.

A 0 (no limit) lets one bad import exhaust memory or fill the disk — only for sources you trust.

App security

Every import is scanned before anything is written: built-in heuristics always run; ClamAV and VirusTotal add signature detection when available. A critical finding pauses the import — you choose Install anyway or Cancel. Flagged apps ask again before they start.

Uninstall these apps?

App folders are permanently removed — they do not go to the Trash. Each app is stopped first; an app mid-start is skipped and reported. Apps packed inside the launcher (an all-in-one or --only build) stay removed until you restore them from Deck tools.

Removed apps

Apps you uninstalled from a launcher that packs them inside the executable. Restore unpacks the copy the launcher already carries — nothing is downloaded. Forget stops offering the restore; the app stays uninstalled.

Forgotten — still uninstalled, no longer offered above. Their record is what keeps them off the deck; restoring brings the app back.
