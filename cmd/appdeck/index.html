🛡 App security

Every import is scanned before anything is written: built-in heuristics always run; ClamAV and VirusTotal add signature detection when available. A critical finding pauses the import — you choose Install anyway or Cancel. Flagged apps ask again before they start.

🗑 Uninstall these apps?

App folders are permanently removed — they do not go to the Trash. Each app is stopped first; an app mid-start is skipped and reported. Apps packed inside the launcher (an all-in-one or --only build) stay removed until you restore them from ⚙ Deck tools.
